**Body:**
I built CORTEX – an open-source alternative to Claude Code / Cursor that runs on any LLM provider.

Features:
• 162 specialist agents (engineering, design, marketing, security, game dev...)
• 45+ LLM providers (OpenRouter, Groq, HuggingFace, NVIDIA, OpenAI, Anthropic...)
• 50+ slash commands, 38 MCP servers
• 4 interfaces: CLI, Electron desktop, Web dashboard, VS Code
• Zero telemetry — 21 modules stubbed at build time
• CORTEX_SIMPLE mode: 7 essential tools for fast responses
• Plugin marketplace, voice I/O, screen vision, offline Ollama mode

No subscriptions. No vendor lock-in. Just git clone and run.

Tech: TypeScript + Bun + Ink (React for CLI)
